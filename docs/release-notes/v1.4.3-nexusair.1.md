## 🇩🇪 Deutsch

### Erste NexusAir-Ausgabe

Dieser Release baut auf AeroACARS v1.4.3 auf und ist die erste eigenständige Ausgabe für **NexusAir**:

- **Umbenennung** — App heißt jetzt überall "NexusAir ACARS" (Fenster-Titel, Tray, Benachrichtigungen, Aktivitätsprotokoll, About-Seite).
- **phpVMS-Anbindung** umgestellt auf `crew.nexusairva.org` (vorher German Sky Group).

- **Fehlerberichte** (freiwillig, anonym) gehen jetzt an unser eigenes GlitchTip unter `tip.nexusairva.org`.
- **Auto-Update** läuft jetzt über unser eigenes GitHub-Repo mit einem neuen, eigenen Signierschlüssel.

### Übernommene Fixes aus v1.4.3

- **Karte:** Rauszoomen hing nicht mehr fest ("Folgen" schaltete sich nur bei echtem Ziehen ab, nicht beim Zoomen); Flugphase jetzt als eigene Zeile im Datenfeld sichtbar; Ereignisfilter entfernt (immer alle Einträge); Kartenschalter-Block verkleinert.
- **Cockpit / Aktiver Flug:** doppelte Flugphasen-Anzeige im Header entfernt; Distanz-Feld im Header zeigt jetzt die echte Gesamtstrecke statt der bisher geflogenen; Karten weiter verkleinert.
- **Gebuchte Flüge:** einheitlicher Leerzustand wie im Cockpit.
- **Logbuch:** fehlgeschlagene Ladeversuche werden jetzt automatisch wiederholt, plus manueller "Erneut versuchen"-Button.
- **CPDLC:** Callsign-Zeile neu verteilt, Eingabefeld verbreitert.
- **Landungen:** Live-Vorschau nach der Landung verdeckt die Liste nicht mehr.

### Hinweis

Client-Update — aktualisiert sich automatisch, kein Wire-Format geändert.

## 🇬🇧 English

### First NexusAir edition

This release builds on AeroACARS v1.4.3 and is the first standalone edition for **NexusAir**:

- **Rebrand** — the app is now "NexusAir ACARS" everywhere (window title, tray, notifications, activity log, About page).
- **phpVMS connection** switched to `crew.nexusairva.org` (previously German Sky Group).
- **Live tracking / MQTT / navdata / aircraft-scan / Discord RPC** now run against `live.nexusairva.org`.
- **Crash reporting** (opt-in, anonymous) now goes to our own GlitchTip at `tip.nexusairva.org`.
- **Auto-update** now runs through our own GitHub repo with a newly generated, dedicated signing key.

### Fixes carried over from v1.4.3

- **Live Map:** zooming out no longer gets stuck ("Follow" now only disengages on a real drag, not a zoom gesture); flight phase now shown as its own row in the data field; event filter bar removed (all entries always shown); map-switcher overlay trimmed down.
- **Cockpit / Active Flight:** duplicate flight-phase display in the header removed; header distance field now shows the real total route distance instead of distance flown so far; cards trimmed down further.
- **Booked Flights:** consistent empty-state treatment matching Cockpit.
- **Logbook:** failed loads now automatically retry, plus a manual "Try again" button.
- **CPDLC:** callsign row redistributed, input widened.
- **Landings:** live preview after touchdown no longer covers the list.

### Note

Client update — auto-updates, no wire-format changes.
