## 🇬🇧 English

### NexusAir

- **GSG brand tag removed** — the VA-identity acronym in the connection-status tag, anonymized callsigns, and pilot-status text now reads "NXS" everywhere instead of "GSG".
- **About page / activity log** personalized.
- **SimBrief username field:** the placeholder example showed the previous maintainer's real SimBrief username — replaced with a generic example (privacy).
- **Process name in Task Manager / Activity Monitor** renamed — was still running internally as "aeroacars-app", now shows "NexusAir ACARS" / "nexusair-acars".

### Fixes carried over from v1.4.4–v1.4.6

- **Landing score reworked:** sink rate is now judged against a target corridor (90–250 fpm) instead of "softer is always better"; runway-utilization tolerance widened.
- **CPDLC:** orphaned instructions are now auto-resolved on handover; "HANDOVER" packets are now checked against the sender.
- **Security:** HTTP redirects can no longer leak the phpVMS API key via a host/scheme/port switch; closed a LAN remote-control PIN leak; paired remote-control devices can now be disconnected.
- **PDF export** (Landing tab) did nothing at all on macOS — fixed.
- **Display:** long info panels weren't scrollable; two notice banners ignored the app's theme; native right-click menu suppressed.
- **Runway detection:** landings at some airports (including EFTP) were matched to a phantom navdata runway entry — now cross-checked against OurAirports.
- Various simulator-data fixes (PMDG 737/777, Fenix A320, X-Plane TAS, MSFS N1) and reliability fixes (Discord RPC rate limit, METAR caching, PIREP form).

Client update — auto-updates, no wire-format changes.
